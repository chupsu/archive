Политика использования файлов для сохранения настроек и условий обработки пользовательских данных

Настоящий веб-сайт https://site.ru использует файлы для сохранения настроек и условий обработки пользовательских данных. Файлы для сохранения настроек и условий обработки пользовательских данных — это небольшие файлы, которые загружаются на компьютер посетителя и помогают обеспечить нормальное и безопасное функционирование веб-сайта. Они позволяют собирать информацию о продуктах, которыми интересуются посетители сайта, а также учитывают использованную при посещении навигацию. Это делается для того, чтобы сделать наши онлайн-предложения более полезными для пользователей.

Компания ООО «Безен Хелскеа РУС» соблюдает права на неприкосновенность частной жизни посетителей веб-сайта и признает важность защиты их персональных данных, поэтому анализ информации с веб-сайта производится на анонимной основе. При посещении настоящего веб-сайта интернет-браузер каждого посетителя передает на сервер компании ООО «Безен Хелскеа РУС» определенные сведения: дату и время посещения, тип браузера, языковые настройки, операционную систему. Информация о том, каким образом используется сайт, не будет привязываться к полному адресу интернет-протокола. Данные сведения сохраняются в журналах подключений в течение ограниченного времени для обеспечения безопасности и надлежащей работы веб-сайта, а также для сбора статистической информации. Настоящим сайтом используется две категории файлов для сохранения настроек и условий обработки пользовательских данных: файлы для сохранения настроек и условий обработки пользовательских данных, необходимые в технических целях, без которых функциональность сайта значительно снизится, и необязательные файлы для сохранения настроек и условий обработки пользовательских данных. Посетители могут в любое время отключить файлы для сохранения настроек и условий обработки пользовательских данных или настроить свой веб-обозреватель для предупреждения о получении таких файлов. Однако если файлы для сохранения настроек и условий обработки пользовательских данных будут выключены, посетители не смогут пользоваться всеми функциями данного веб-сайта. На веб-сайте мы используем собственные необязательные файлы для сохранения настроек и условий обработки пользовательских данных, которые помогают понять, как сделать сервисы более привлекательными для посетителей. Необязательные файлы для сохранения настроек и условий обработки пользовательских данных помогают узнать, как долго посетитель просматривал страницу или на какие именно страницы заходил.

Вся информация, представленная на этом сайте/странице, носит исключительно информационный характер и не является публичной офертой. Материалы не заменяют профессиональную медицинскую диагностику или лечение. При любых проблемах со здоровьем необходимо обязательно обратиться к врачу
